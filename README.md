# Library-Management-System
Library Management System is a Console-Based Application.

Library Management System is a Python application designed to provide librarians and users with an efficient and easy-to-use platform for managing books, members, and borrowing activities. It securely stores book details, member information, borrowing records, due dates, and overdue transactions. The system automates routine tasks such as adding new books, registering members, issuing books, and processing returns, ensuring smooth and organized library operations.

# Features

1)Implemented book and member management modules that support add, update, search, and delete operations.

2)Designed a borrowing and returning system with automatic due-date calculation and overdue tracking.

3)Developed a structured and modular application using Python classes for books, members, and library operations.

4)Integrated an SQLite database to efficiently store and manage books, members, and transaction records.
